# Memoria TFM — Safi (Asistente multiagente de finanzas personales)

Borradores de la memoria, capítulo por capítulo, en Markdown. Flujo: redactar aquí →
Néstor revisa/personaliza → montar en Word/Docs → exportar a **PDF** (máx. 50-60 págs).

> **Regla de oro:** escrito en primera persona, con voz propia y anclado en la experiencia
> real (control de finanzas familiares en Excel). Cada capítulo se edita a mano para que sea
> genuinamente del autor (EBIS penaliza el texto de IA sin adaptación).
